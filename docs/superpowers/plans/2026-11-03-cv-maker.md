# Bikin CV — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Web statis "Bikin CV — Standar Indonesia" yang mengubah isian form jadi CV A4 1 halaman, bisa dicetak ke PDF dan diekspor ke DOCX, siap di-host di GitHub Pages.

**Architecture:** SPA tanpa bundler: `index.html` + ES modules. `js/schema.js` = satu-satunya definisi section/field; `js/store.js` = state + localStorage; `js/preview.js` merender state → DOM `.cv-sheet` yang dipakai bersama oleh tampilan layar dan print; `js/docx.js` membangun DOCX di klien memakai `vendor/docx.umd.cjs`.

**Tech Stack:** HTML, CSS, ES2022 modules, `docx@9.15.1` (UMD, vendored), GitHub Pages. Tanpa framework, tanpa build step, tanpa dependensi runtime eksternal.

**Spec:** `docs/superpowers/specs/2026-11-03-cv-maker-design.md`

## Global Constraints

- Tanpa build step; semua file yang di-commit bisa langsung disajikan apa adanya.
- Tanpa request jaringan eksternal saat runtime (tidak ada CDN/webfont/analytics). CSP: `default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'`.
- Teks user dirender lewat `textContent`/`createElement`, tidak pernah `innerHTML`.
- CSS print: `@page { size: A4; margin: 0 }`; area cetak 297×210mm; padding isi 16mm semua sisi; lebar isi 178mm.
- Geometri DOCX sama: margin 1.6cm semua sisi (konten 10091 twips), `LABEL_TAB` 44mm.
- Nama file keluaran: `CV-<nama>-<posisi>`, spasi → `-`, buang `/\:*?"<>|`.
- Bahasa UI: Indonesia, sapaan netral ("kamu"), tanpa emoji.
- Font: `Calibri, Carlito, Arial, sans-serif` (font sistem).
- Mobile-first; target utama Chrome Android 390×844, juga Chrome desktop & Safari iOS.

## Review Focus

- **Isi kepanjangan (>1 halaman)** — badge harus berubah ke "2 halaman" sebelum user mencetak, dan tidak ada entri terbelah dua halaman.
- **Data kosong / section di-skip** — CV tetap tercetak rapi tanpa heading menggantung atau baris `undefined`.
- **Teks panjang tanpa spasi** (email, URL LinkedIn, alamat) — tidak boleh mendorong layout melewati margin; harus wrap.
- **Foto besar / bukan gambar** — upload 10MB atau file PDF harus gagal dengan pesan jelas, bukan membuat tab crash (kuota localStorage).
- **Print dari halaman yang sudah di-scroll & preview di-scale** — PDF harus tetap 1 halaman penuh A4, bukan hasil scaling.

### Task 1: Scaffold, schema, util

**Files:** Create `index.html`, `js/schema.js`, `js/util.js`, `css/app.css` (kerangka), `.gitignore`

**Interfaces (Produces):**
- `schema.js`: `export const SECTIONS: {id,label,repeatable,skippable,tip}[]`; `export const TEMPLATES: {freshgrad|experienced:{label,order,hide}}`; `export function blankState(): State`; `export function sectionLabel(id): string`.
- `util.js`: `export function slug(s): string`; `export function filename(state, ext): string`; `export function setPrintTitle(title): () => void`; `export function downloadBlob(blob, name): void`; `export function debounce(fn, ms): fn`.
- State shape persis seperti bagian "Model data" di spec.

**Steps:**
- [ ] Tulis `schema.js` memuat 9 section (ringkasan, dataPribadi, pendidikan, kerja, organisasi, keterampilan, sertifikasi, bahasa, referensi) + tip inline tiap section + `blankState()`.
- [ ] Tulis `util.js` (slug/filename/setPrintTitle/downloadBlob/debounce).
- [ ] Tulis `index.html` kerangka: `<main>` dengan `#form-panel`, `#preview-panel`, toolbar (`#badge`, `#btn-pdf`, `#btn-docx`, `#btn-json`, `#btn-import`, `#template`), `<script type="module" src="js/main.js">`, meta CSP.
- [ ] Verifikasi: `node --input-type=module -e "import('/root/CV/web/js/schema.js').then(m=>console.log(Object.keys(m.blankState().header)))"` mencetak 7 kunci header.

### Task 2: `css/cv.css` + `js/preview.js`

**Files:** Create `css/cv.css`, `js/preview.js`

**Interfaces:**
- Consumes: `State` dari Task 1.
- Produces: `export function renderPreview(root, state): void` (mengisi `root` dengan `.cv-sheet`), `export function measure(sheet): {heightPx, limitPx: 1001.8, pages: 1|2}`.

**Steps:**
- [ ] Ekstrak `css/cv.css` dari `/root/CV/cv-template.html`: `@page`, `.cv-sheet` (210×297mm, padding 16mm, `box-sizing:border-box`, tanpa `min-height`), header/foto/section/entri/bullet. Class lama dipertahankan; `body`-level padding dipindah ke `.cv-sheet`.
- [ ] `renderPreview` membangun DOM via `createElement`; section kosong & yang ada di `state.hide` tidak dirender; bullet kosong dilewati; foto dirender `<img>` 28×38mm kalau `header.foto` ada.
- [ ] `measure` menghitung `Math.max(sheet.scrollHeight, lastChild bottom - sheet top)`, `pages = heightPx > limitPx ? 2 : 1`.
- [ ] Verifikasi headless: render state contoh penuh → `measure().pages === 1`; state 3 kerja × 4 bullet → `pages === 2`; `sheet.scrollWidth <= 794`.

### Task 3: `js/store.js` + `js/photo.js`

**Files:** Create `js/store.js`, `js/photo.js`

**Interfaces:**
- Produces: `store.load(): State` (fallback `blankState()`, migrasi `version`), `store.save(state)` (localStorage, lempar error kalau >5MB), `store.toJSONFile(state): Blob`, `store.fromJSONFile(file): Promise<State>` (tolak `version` tak dikenal, ambil hanya field di `blankState()`), `store.clear()`.
- `photo.processPhoto(file): Promise<string>` (JPEG dataURL 354×472), `photo.estimateBytes(dataURL): number`.

**Steps:**
- [ ] Validasi foto: `file.type` harus `image/*`, `file.size` ≤ 8MB, else `throw new Error("...")` berbahasa Indonesia.
- [ ] Crop tengah ke rasio 3:4 lalu `canvas.toDataURL("image/jpeg", 0.8)`.
- [ ] Verifikasi: import modul di node untuk `fromJSONFile` dengan JSON rusak → promise reject, dengan `version: 99` → reject, dengan field asing → dibuang.
